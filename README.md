About Me
-----
  
Heya, I'm a student at **42 Berlin**. Outside of the projects for the cor curriculum I am working on understanding more about how code becomes executable. Currently looking into how code get's compiled and linked, as well as working on a malloc rewrite to understand Heap memory better.

My other main interests are low-level programming with Assembly and reading good documentation.

Featured Projects
-----

[nm](https://github.com/aufklaeranlage/nm)

This rewrite of `nm` was a good exercise in understanding ELF files. How code get's saved in different forms and is understood by the system for linking and execution.

[ft_ls](https://github.com/aufklaeranlage/ft_ls)

While rewriting `ls` I could learn a lot about how linux stores information about files and devices, about the general structure of the file system on linux and how to properly traverse it with the already provided functions of the standard library.

[libchooks](https://github.com/aufklaeranlage/libchooks)

This small hooking library for dynamically linked programs taught me a lot about how linking, pre-loading etc. works. The library isn't that complicated (basically a glorified `dlsym` call) but learning more about where and how program linking happens together with the understanding of ELF from `nm` was the main takeaway for me.
